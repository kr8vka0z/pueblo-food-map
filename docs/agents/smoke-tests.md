# Deploy smoke tests

Moved from AGENTS.md, section Hosting and deploys.

Both deploy workflows run one script, `scripts/smoke.sh <origin> [--canonical-host <host>]`, right after `wrangler deploy`: `deploy-prod.yml` against https://pueblo-food-map.kyle-boyd.workers.dev with `--canonical-host pueblofoodmap.com`, `deploy-dev.yml` against https://pueblo-food-map-staging.kyle-boyd.workers.dev (kept on by `env.staging` `workers_dev: true`). It checks `/`, `/venues`, one `/venue/<id>`, `/es`, `/es/venues`, one `/es/venue/<id>`, one `/report/<id>`, the four SEO hubs (`/food-pantries`, `/snap-wic-stores`, `/community-gardens`, `/blessing-boxes`) and their `/es` twins, `/sitemap.xml`, `/robots.txt` and `/llms.txt` (200), the `/es` pages for `<html lang="es">` in the response body, an unmatched page and unknown `/venue/<id>`, `/es/venue/<id>`, `/event/<id>` and `/es/event/<id>` URLs (all 404, so a missing `events` table can never surface as a 500), and that the origin sends `X-Robots-Tag: noindex`. With `--canonical-host` (prod only) it also fails if `https://pueblofoodmap.com/` sends noindex. Every check retries 6 times, 10 s apart, because a fresh deployment takes a moment to reach every location. Both call the Worker's workers.dev origin, never the zone host: Bot Fight Mode answers 403 to GitHub runners there (Free plan, no WAF skip, #773). Run it by hand the same way; it only sends GETs.
