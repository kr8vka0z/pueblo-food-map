Map / List switch — options

Kyle wants to keep a way to flip between the map and the list, just not the dark two-part switch jammed into the search bar. Every screen already carries the Filters button in the magnifier spot (#513). Each option names the well-known apps that use the same pattern, so it will feel familiar to visitors.

  • A — most common pattern on map-and-list apps; one word says what happens; frees the search bar entirely (more room for typing and for the Filters button). Must hide while a place card is open so it doesn't sit on top of it.
  • B — least work; fixes the heavy dark look but stays icon-only.
  • C — the "real map app" feel; biggest build, and it competes with the place cards and the walking-route strip (#509) for the bottom of the screen.
  • D — clearest labels; costs a strip of map and adds a third layer at the top.
  • On a computer the site also flips between a full map and a full list today (no side-by-side), so whichever option wins is used there too, at the same spot.
